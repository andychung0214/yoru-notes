# 測試計畫

## 自動功能驗證
- [x] 八首曲目、id 唯一、來源使用 HTTPS。
- [x] 中文、日文、羅馬字、原作名稱搜尋與大小寫、前後空白處理。
- [x] 小說／動畫分類、收藏加入移除、空收藏與清除篩選。
- [x] 歌曲 hash 切換後故事資料同步，人物頁顯示。
- [x] 主題與收藏重新整理後仍存在。
- [x] 日中雙語、日文、中文三種模式與缺少語言的資料支援。
- [x] 合法 JSON、單語資料、空陣列、空白行、數字欄位、無效 JSON、超過 500 行與超長欄位。
- [x] JSON 檔案匯入、HTML 當作純文字，清除匯入內容。
- [x] 示範內容標為非 YOASOBI 歌詞。
- [x] localStorage 被拒絕、損壞內容的恢復與提示。
- [x] 直接 file:// 開啟，以及 HTTP 伺服器載入。

## 手動／視覺驗證
- [x] 檢視桌機 1440 px 截圖：主視覺、閱讀欄、曲目索引與字體沒有重疊。
- [x] 檢視手機 390 px 截圖：曲目可水平滑動，內容堆疊，匯入對話框可閱讀。
- [x] 360、390、768、1024、1440 px 的 document 寬度未超過 viewport。
- [ ] Safari 與 Firefox 實測。
- [ ] 實體 iOS／Android 的觸控、檔案選擇器與虛擬鍵盤。
- [ ] 外部 YouTube 的各地區實際影片播放。

## 無障礙
- [x] 使用語意按鈕、輸入欄標籤、日文 lang、可見焦點。
- [x] 原生 dialog 支援 Escape，焦點可返回觸發控制項。
- [x] 跳至主要內容保留當前歌曲，不改變路由（回歸測試）。
- [x] 儲存與錯誤提示採 role=status / role=alert。
- [x] 樣式尊重 prefers-reduced-motion，沒有自動播放。
- [ ] 螢幕閱讀器 NVDA／VoiceOver 與完整 WCAG 稽核。
- [ ] 全頁 200% 文字縮放與作業系統高對比模式。

## 重現
`npm test` 執行 Node 內建測試。安裝選用 Playwright 後執行 `npm run test:browser`；預設使用本機 Edge。測試啟動獨立暫存瀏覽器 context，不存取使用者瀏覽器登入狀態，不讀取憑證。

自動測試不把未執行的人工檢查視為通過。完整證據與限制請參照 VERIFICATION.md。
