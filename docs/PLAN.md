# YORU Notes｜夜讀音樂室 Implementation Plan

執行方式：使用 executing-plans 在本次工作階段依序實作，完成後以 requesting-code-review 獨立審查。

## 需求與設計
建立給 YOASOBI 聽眾使用的歌曲與故事閱讀網站。HTML、CSS、Vanilla JavaScript，無建構需求、無後端、無執行時套件。可直接開啟 index.html，亦可部署到靜態主機。此產品是音樂資料館，需求中的「遊戲」不代表需要加入遊戲玩法。

名稱：YORU Notes；中文名稱：夜讀音樂室；類型：音樂 × 文學粉絲資料館。
比較方案：唱片封面牆適合探索但不利閱讀；時間軸適合生涯介紹但不利歌曲切換；採曲目索引搭配閱讀頁，讓日中對照與原作關係在同一頁可見。

## 範圍
- 十六首精選歌曲；搜尋日文、中文與原作名稱，分類與收藏。
- 歌曲詳細資料、原作小說與動畫關係、可追溯來源。
- 日文／正體中文／雙語閱讀；使用者匯入自行取得授權的逐行 JSON。
- ikura 基本資料與來源，森林綠與酒紅主題、燙金點綴。
- 個人收藏、主題與歌詞存於 localStorage；儲存失敗時提示並維持本次操作。
- 不收錄未授權歌詞、翻譯、音訊、官方照片或專輯封面；不冒充官方。

## 檔案責任
- index.html：語意結構、導覽、歌詞匯入對話框。
- styles.css：色彩、版面、響應式與焦點。
- data.js：十六首歌曲的公開資料與来源連結。
- core.js：搜尋、匯入驗證、儲存邊界，可在 Node 與瀏覽器共用。
- app.js：DOM 呈現、事件與狀態。
- tests/core.test.cjs：Node 內建測試；tests/browser.cjs：選用 Playwright 瀏覽器測試。
- docs：設計、測試、執行紀錄；README、LICENSE、CONTRIBUTING。

## 風險與驗收
1. 歌詞授權：預設顯示明確空狀態；示範句為原創介面測試文字，絕不標為歌曲歌詞。
2. 非法 JSON／過長檔案／HTML 字串：限制 200 KB、500 行、每欄 1000 字元；文字一律 textContent。
3. localStorage 拒絕／損壞：不可使網站崩潰，呈現儲存提示。
4. 搜尋無結果／空收藏：顯示清除條件操作；不能留下過期結果。
5. 手機與鍵盤：360 px 無水平溢出、控制元件至少 44 px、明顯焦點、對話框 Escape 關閉與焦點返回。
6. Git：目前父目錄無儲存庫；新建獨立儲存庫。不讀取憑證檔。remote 未提供則推送明確列為受阻，不虛構成功。
