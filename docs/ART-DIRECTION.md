# 視覺方向

音樂收藏者的深夜書房：深森林綠封面、酒紅標記、燙金細線，搭配像唱片內頁的紙色閱讀區。標誌為原創同心唱片與書頁組合；不用官方標誌與圖片。

## 色票
森林綠 #173D35；深綠 #102C27；酒紅 #702D40；燙金 #D6B775；紙白 #F5F2E9；墨色 #243D35；次要文字 #667269。酒紅主題將深色主背景替換為 #492331。

## 字體
標題使用 Georgia / Noto Serif TC / 系統明體，日文歌曲標題使用 Yu Mincho。內文使用系統無襯線（Segoe UI、Noto Sans TC、Microsoft JhengHei），標籤使用等寬字。全數本機字體，不依賴遠端載入。

## 版面與元件
桌機 276 px 曲目索引＋彈性閱讀欄。閱讀欄有寬幅深綠封面、原創 CSS 唱片圖像、紙色內容。邊線優先於陰影，避免過多卡片。主標題 48–72 px，內文 16 px、行高 1.8。主按鈕 44 px 高，互動焦點 3 px 金色外框。
900 px 以下索引移至上方、歌曲採橫向可捲動列表；600 px 以下直向閱讀、資訊區塊堆疊、縮小装飾唱片。

## 動畫原則
只使用 150 ms 的顏色過渡；不自動播放音樂、不使用連續旋轉或滾動劫持。尊重 prefers-reduced-motion。

## 禁止事項
不使用漸層文字、玻璃效果、任意表情符號、虛構歌詞、假播放進度或未授權影像。不以裝飾取代可讀標籤。
