## 決策與限制
- 使用純靜態資料館而非遊戲：需求核心為音樂資訊閱讀；不加入無關遊戲機制。
- 首版八首精選、來源整理，不冒稱完整目錄。
- 沒有歌詞授權，因此提供匯入與切換，未內附完整歌詞或全文翻譯。
- 新建獨立子目錄儲存庫；父目錄不是 Git 儲存庫，避免納入其他專案。
- 未實测 Safari、Firefox、實體觸控、螢幕閱讀器、完整 WCAG 或外部 MV 播放。測試通過僅代表記錄中的範圍。
- 首版後續已推送至使用者提供的 GitHub 儲存庫，並啟用 feature/yoru-notes 分支根目錄的 GitHub Pages。
