# 平假名與片假名閱讀

在既有五種歌詞顯示模式上，新增只看平假名、只看片假名、全部對照。全部對照順序為日文原文、平假名、片假名、正體中文、英文；日中英對照仍只呈現三種語言。兩種假名為日文讀音，不是新增翻譯語言。

匯入資料新增選填 hiragana / katakana 文字欄位。讀取舊資料時補空字串；未提供顯示中文提示。保留純文字安全呈現、200 KB／500 行／每欄 1000 字元限制。假名內容使用 lang=ja，缺漏提示使用 zh-Hant。不自行猜測漢字讀音，不自動產生注音。

實作順序：核心測試先失敗 → 欄位驗證與顯示模式 → 原創範例與匯入说明 → 瀏覽器回歸與360px截圖 → 審查 → 提交推送與公開版本驗證。

驗收：兩種假名单獨匯入有效、全部五欄按順序呈現、既有模式不變、缺漏提示與lang正確、儲存重新整理後保留、直接預植舊localStorage可讀取、手機八個選項換行且無溢出。

## 追加漢字欄位

新增選填 kanji（日文漢字表記）及只看漢字模式，不從假名推測漢字，也不刪除日文原文。全部對照依序呈現日文、漢字、平假名、片假名、中文、英文。總共九種模式，漢字使用 lang=ja。驗收涵蓋單欄匯入、缺漏提示、重新整理、純文字安全及手機換行。
