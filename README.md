# YORU Notes｜夜讀音樂室

一首歌，一段故事。森林綠、酒紅與燙金的 YOASOBI 非官方音樂資料館，使用 HTML、CSS、Vanilla JavaScript，無後端、無建構步驟。

## 專案介紹與特色
本專案是音樂與文學閱讀網站，不含遊戲玩法、積分或勝負。收錄八首精選歌曲的公開基本資料、原作關係及來源；並提供 ikura 人物介紹。

- 依日文／中文歌名、羅馬字、小說名、動畫名搜尋。
- 小說、動畫與收藏篩選；收藏保留於此瀏覽器。
- 歌曲與故事閱讀頁，提供原作來源與官方 MV 外連。
- 個人 JSON 歌詞匯入、日文／正體中文／雙語切換、逐首清除。
- 森林綠／酒紅主題切換、桌機與行動版面、鍵盤焦點與原生對話框。
- 所有裝飾皆為原創 CSS／SVG，無第三方字體或影像請求。

## 安裝與執行
直接以現代瀏覽器開啟 **index.html** 即可使用。不需要 npm install。為取得較一致的 localStorage 行為，建議使用靜態 HTTP 伺服器：

```sh
python -m http.server 8080 --bind 127.0.0.1
```

然後開啟 http://127.0.0.1:8080 。Python 僅為可選的本機靜態檔案工具，不是產品後端。也可使用編輯器的靜態預覽功能。

## 操作方式
1. 點選曲目或輸入關鍵字。手機版可水平滑動曲目索引。
2. 使用「歌曲與故事」閱讀整理文字與來源；「前往官方 MV」會另開分頁，不在本站播放。
3. 點選「歌詞對照」→「匯入歌詞」，貼上 JSON 或選擇檔案。
4. 匯入後切換「日中對照／只看日文／只看中文」。未提供的語言會顯示提示，不會自行翻譯。
5. 點選「加入收藏」、分類「收藏」檢視，右上切換書房色調。
6. 點選「關於 ikura」閱讀人物介紹。支援 `#song/yuusha` 等歌曲連結與瀏覽器上一頁。

### 歌詞格式
只能匯入你有權使用的歌詞與翻譯。以下是原創介面範例，**不是 YOASOBI 歌詞**：

```json
[
  {"ja":"これは表示を確かめるための例文です。", "zh":"這是用來確認顯示效果的範例句子。"},
  {"ja":"ここに自分のテキストを入れます。", "zh":"在這裡放入自己的文字。"}
]
```

上限 200,000 bytes、500 行、每種語言每行 1,000 字元。每行至少一種語言。新匯入會取代該首既有內容。所有內容都當作純文字呈現；HTML 不會被執行。

## 測試方式
安裝 Node.js 20 或以上後，不需安裝套件即可執行：
```sh
npm test
```

瀏覽器測試使用可選的 Playwright，網站本身完全不依賴它：
```sh
npm install --no-save --package-lock=false playwright
npm run test:browser
```
預設使用本機 Microsoft Edge。使用 Chrome 時將環境變數 `BROWSER_CHANNEL` 設為 `chrome`。測試會啟動隨機本機連接埠、執行案例、輸出 `test-results/` 截圖及 JSON，然後自動關閉。結果檔不加入 Git。

## 靜態網站部署
將 `index.html`、`styles.css`、`app.js`、`core.js`、`data.js` 與 `assets/` 一併上傳至 GitHub Pages、一般靜態託管或 NAS Web Station 的網站根目錄。全部使用相對路徑，支援子目錄部署，不需要路由重寫。建議 HTTPS。無需部署 tests、docs 或 node_modules。

Git push 只推送版本控制內容，不等於已設定網站託管或已上線。尚未提供 remote 時，不能宣稱推送完成。

## 已知限制與隱私
- **不附完整歌曲歌詞或其翻譯。** 語言切換呈現使用者匯入內容；不包含自動翻譯、歌詞抓取或授權資料庫。
- 八首精選並非完整作品目錄，資料核對日期為 2026-09-23，不自動更新。
- 官方 MV 與來源為外部服務，可能因地區、下架或網址變更而無法使用；未驗證實際影片播放。
- 收藏、主題與個人文字只留在目前瀏覽器的 localStorage，沒有帳號同步。私人瀏覽、容量不足或拒絕儲存時會提示，當次頁面仍可用。清除網站資料會失去內容。
- file:// 下的儲存行為因瀏覽器而異。換檔案位置、換協定或換連接埠不會共用收藏。
- 未提供匯出或跨裝置備份；清除匯入內容前請保留自己的原始檔案。
- 實测範圍見 docs/VERIFICATION.md；尚未完成 Safari、Firefox、實體觸控裝置與螢幕閱讀器實测。
